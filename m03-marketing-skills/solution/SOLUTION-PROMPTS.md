# Module 03 Solution: Building the Platform Best Practices Skill

Run the steps below in order from this folder in Claude Code to follow along with the solution video.

First, create a `gsj-platform-best-practices/references/` folder and put `gsj-platform-specs.xlsx` (from `starter/`) in it.

**P1: Create the skill**
```
Create a skill called the GSJ platform best practices. It should check or adapt ad and social copy against Google RSA, Meta, and LinkedIn formatting rules and character limits. Here are the current specs for each platform. Build the skill so it reads this file rather than guessing at limits. Character counts must be counted exactly. Never estimated. If copy is over the limit, say by how much.
Use the GSJ platform specs file in the references folder.
```

**P2: Test the skill**
```
/gsj-platform-best-practices Review this LinkedIn post and tell me what needs to change.
"Big announcement from Groundswell Juice Co: check out our new Fall Harvest Blend, available at every location starting this weekend:
https://groundswelljuice.com/fall-harvest - made with pumpkin, apple, and cinnamon, sourced from a local farm partnership we've built over the past two seasons, and designed to be the perfect seasonal option for anyone looking for something warm and comforting without the sugar crash that comes with most fall drinks people are used to grabbing this time of year. Learn more on our site!"
```
