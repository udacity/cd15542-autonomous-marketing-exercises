# Solstice Active — claims tracker

Source of truth for `sa-product-accuracy`. Every claim in outgoing copy gets matched against this file — never approved from memory.

## Approved (A)

| Row | Claim | Limits | Required caveat |
|-----|-------|--------|------------------|
| A1 | Four-way stretch knit | Applies to Momentum Legging, Momentum Jogger, Pulse Sports Bra | None |
| A2 | Moisture-wicking / breathable fabric | Applies to all performance lines, including Pulse Sports Bra | None |
| A3 | Compression fit through waistband/leggings | Applies to Momentum Legging only | None |
| A4 | Squat-proof / opaque at full stretch | Momentum Legging only, tested at retail fit standard | None |
| A5 | Four-way stretch supports range of motion in training | General movement claim, not a medical/recovery claim | Do not extend to "prevents injury" or "aids recovery" |
| A6 | True-to-size fit, sizing chart available | Per Solstice's own sizing chart | Must direct to current sizing chart, not a fixed number |
| A7 | High-impact support / stays in place during high-impact movement (jump squats, running, burpees) without readjustment | Pulse Sports Bra only, tested at high-impact activity level | None |

## Banned (B)

| Row | Claim / phrasing | Reason on file |
|-----|-------------------|-----------------|
| B1 | Any named-competitor comparison ("better than [Competitor]," "outperforms [Competitor]," "unlike [Competitor]...") | Solstice has never run a substantiated head-to-head comparative test against any named competitor. Banned outright regardless of source (written copy or a customer's own quoted words). |
| B2 | "Clinically proven" (recovery, performance, or any health effect) | No clinical study has been conducted or commissioned by Solstice. |
| B3 | "Cures" or "eliminates" muscle soreness / injury | Overreach past A5; fabric supports movement, it does not treat or prevent injury. |
| B4 | "Sweat-proof" / "100% dry" | Overreach past A2; moisture-wicking manages, does not eliminate, moisture. |
| B5 | Unqualified "sustainable" / "eco-friendly" (no specifics) | No sourcing/materials tracker row currently approved for a sustainability claim; flag as UNVERIFIED with a request for the specific material/program before using any green claim. |

## Known unverified (examples of the process, not an exhaustive list)

- "Cut my recovery time in half" — a customer's personal impression; no A-row supports a quantified recovery claim. UNVERIFIED unless a new row is added with a real proof source.
- Any comparison to a competitor not covered above — always resolves to B1 regardless of wording.

## Notes

- This tracker needs a human owner (product marketing) who keeps it current as new fabric tech or substantiated tests become available. A claim absent from this file is not automatically wrong — it's UNVERIFIED until someone adds the row with a proof source.
- B1 is the row this workspace's escalation pattern is built around: it's the cleanest, most unambiguous BANNED case for teaching purposes, since a competitor comparison volunteered by a happy customer is common and the audit still has to catch it every time.
