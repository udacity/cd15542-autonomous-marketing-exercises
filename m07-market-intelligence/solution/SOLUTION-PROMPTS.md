# Module 07 Solution: Building the Competitor Crisis Alert Agent

Run the steps below in order from this folder in Claude Code to follow along with the solution video.

**P1: Plan the agent (plan mode, Shift+Tab)**
```
I want a new agent that checks daily for sudden bad news or PR spikes about our competitors, so we're not finding out a week late. Our competitors are grouped into three tiers by how closely they compete with us. I want the agent to treat a Tier 1 competitor's bad news as more urgent than the same kind of news about a Tier 3 competitor. Ask me any questions you need to figure out how urgent is 'urgent enough' and how the alert should change by tier!
```
