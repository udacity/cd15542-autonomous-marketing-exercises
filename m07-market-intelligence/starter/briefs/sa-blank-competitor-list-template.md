---
**How to fill this in:**
1. Replace every `[bracketed]` placeholder. An unknown parent company or
   tier boundary is a gap to flag, not fill with a guess.
2. Aim for 3–7 names per tier. Fewer than 3 in Tier 1 usually means the
   tier is drawn too narrow; more than 7 in any tier usually means it's
   too wide to search efficiently.
3. This list steers every source type in the agent — Web Search, News,
   and AI Citation Watch all read this file first. A brand left off
   here never gets checked, in any source.
4. Once filled in, point `sa-market-intelligence-agent`'s
   `sa-competitor-watch` skill reference at this file (or replace
   `references/sa-competitor-list.md` with it) and run the sweep.
