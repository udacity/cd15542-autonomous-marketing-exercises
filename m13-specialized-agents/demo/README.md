# Module 13 Instructor Demo — Brand-Safety Auditor (Demo 1 and Demo 2)

Open this folder in Claude Code. The auditor hasn't been built yet. Building it is what Demo 1 records.

## What's here
- `CLAUDE.md`: project facts and the workflow rule. Walked through on camera in both demos.
- `brand/brg-brand-bible.md`: voice pillars, Fair Housing rules, and the required disclosure.
- `listings/brg-142-ashgrove-lane.md`: the only fact source for this property. It has no "Approved language" section yet. Demo 2 adds one.
- `.claude/skills/brg-brand-voice/SKILL.md`: the rules the writer and the auditor both use (words on the page).
- `.claude/skills/brg-fair-housing-accuracy/SKILL.md`: the rules only the auditor uses (claims checked against the listing sheet), plus channel rules.
- `.claude/agents/brg-listing-writer.md`: the writer that produced the Demo 2 batch. Its paid/short-form instruction is the upstream cause Demo 2 finds and fixes.
- `test-content/brg-test-email.md`: the Demo 1 test, with two planted errors.
- `content-batch-demo2/`: five assets for Demo 2 (email, Instagram, Meta ad, video script, listing page).
- `practice-files/` and `LEARNER-PROMPTS.md`: a practice kit for learners, with copy-paste prompts and expected results.

## Reset before re-recording
Before the first take, copy this whole folder to `instructor-demo-clean/`. To reset between takes, delete this folder and copy `instructor-demo-clean/` back. The finished end state is in `../instructor-demo-key/`.
